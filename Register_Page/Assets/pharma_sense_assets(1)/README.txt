Pharma Sense UI reference assets

Files:
- logo.png       Cropped logo from the supplied screenshot.
- logo.svg       Clean vector recreation of the medical-cross logo.
- icons/         Small outline SVG icons matching the screenshot:
                 user, mail, phone, lock, eye, check, close, minus.
- theme.css      CSS :root variables for the color composition, spacing,
                 radius, shadow and typography.

Core colors:
Primary green  #0D836B
Dark text      #2C3447
Page background #F8F8F8
White          #FFFFFF
Input border   #E6E7EA
Muted text     #7A808B
Required/error #E0525D

Tip:
Use the SVG icons as <img src="icons/user.svg"> or inline the SVG and
set stroke="currentColor" so CSS can control the icon color.
